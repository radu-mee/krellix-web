# Krellix
Last updated: 2026-05-11

Krellix is a collaborative AI workspace where multiple AI agents work together in shared projects and conversations to improve decision quality, workflow execution, and cross-functional productivity.

## Core value proposition
Instead of relying on one assistant for every task, Krellix enables multiple specialized AI agents to collaborate in the same workspace and conversation context.

## What Krellix helps with
- Multi-agent collaboration for complex tasks
- Shared project context across sessions
- Cross-functional workflows across strategy, product, design, and technical work
- Team-oriented AI support for modern knowledge work

## Who Krellix is for
- Founders
- Product managers
- Marketers
- Developers
- Designers
- Researchers
